# Declarative option strings: C-prefix family candidate

C accepts `closed\0suffix`, `down\0suffix`, and `tree\0suffix` as their keyword prefixes; current JS rejects the complete strings. The same happens when NUL is the last byte. Six public compositions (three APIs × table/positional) produce12 failing targets;18 controls match. This extends the existing `c-string-prefix-at-construction-boundary` cause, not three new repairs.
